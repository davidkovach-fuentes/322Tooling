8: # Parsimonious takes a PEG (not a CFG). Key differences from textbook BNF:
9: #
10: #   * "/" is ordered choice: first alternative that succeeds wins.
11: #     Unlike "|", there is no ambiguity — priority is left-to-right.
12: #   * No separate lexer. Tokens, whitespace, and structure live here together.
13: #   * No left recursion. Write "term (op term)*" instead of "expr = expr op term".
14: #   * Quantifiers (*, +, ?) are greedy.
15: #   * Lookahead: "&x" (positive), "!x" (negative) — match without consuming.
16: #
17: # Pipeline with Parsimonious:
18: #   1. This file  →  Grammar(...) in lb_parser.py  →  concrete parse tree
19: #   2. NodeVisitor in LBi.py walks that tree  →  evaluated result / AST / IR
20: #
21: # Syntax cheat-sheet:
22: #   "lit"           exact string literal
23: #   ~r"regex"       regex (prefix ~); optional flags after the closing quote
24: #   a b c           sequence
25: #   a / b           ordered choice
26: #   x?  x*  x+      optional / zero-or-more / one-or-more
27: #   ( ... )         grouping
28: #   # comment       line comment (this file)
29: #
30: # First rule is the default start symbol for grammar.parse(...).
31: # Docs: https://github.com/erikrose/parsimonious
