## Translating an LB function 

1. For each variable _v_ declared by instruction _i_ in a scope _s_ 

   - Rename _v_ (only) in _i_ to a new and unique name _z_ 

   - _v_ -> _z_ 

   - Remember the mapping 

         - (e.g., _s.map[v] = z_ ) 

2. For each instruction _i_ of a function 

   - For each variable _v_ referenced by _i_ 

      - _s i v_ 

      - Find the innermost scope (starting from ) that declares before _i_ in the original code 

      - If _s_ exists, Function parameters 

      - then change the reference _v_ of _i_ from _v_ to _s.map[v]_ 

3. Remove all nested scopes

## Translating continue 

- Let _i_ be a continue instruction 

- Fetch the innermost loop _w_ that _i_ belongs to: _w = Loop[i]_ 

- _w_ : 

- Fetch the label placed just before the condition of _l_cond = condLabels[w]_ 

- _w:_ 

- Generate a jump to the condition code of _br l_cond_ 

41 

## Translating break 

- Let _i_ be a break instruction 

- Fetch the innermost loop _w_ that _i_ belongs to: _w = Loop[i]_ 

- Fetch the exit label of _w_ : 

   - _l_exit = endWhile[w]_ 

- w: 

- Generate a jump to leave the loop _br l_exit_
